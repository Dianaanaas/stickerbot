# Бот поддержки для магазина наклеек по номерам

## Что делает бот
- Приветствие + главное меню (FAQ, поддержка, ссылка на сайт)
- Раздел FAQ с ответами на частые вопросы (доставка, оплата, размеры, трек-номер)
- Форма обращения в поддержку: категория → номер заказа → текст сообщения
- Все обращения сохраняются в базу (SQLite) и пересылаются в ваш админ-чат
- Вы отвечаете клиенту прямо из админ-чата командой `/reply <номер> <текст>`
- Простая защита от спама (rate limit)

---

## Шаг 1. Создать бота в Telegram

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота (например: `Наклейки по номерам`)
4. Введите username бота — обязательно заканчивается на `bot` (например: `stickers_support_bot`)
5. BotFather пришлёт токен вида `123456789:AAExampleTokenHere` — скопируйте его

## Шаг 2. Узнать ID админ-чата

Вариант А — если поддержку ведёте только вы:
1. Напишите своему боту любое сообщение (пока не запущен — не страшно)
2. После запуска бота узнать свой ID можно через бота **@userinfobot** — напишите ему `/start`, он покажет ваш ID

Вариант Б — если поддержку ведёт команда:
1. Создайте группу в Telegram, добавьте туда нужных людей
2. Добавьте в группу бота **@userinfobot**, он покажет ID группы (число со знаком минус, например `-1001234567890`)
3. Удалите @userinfobot из группы, добавьте туда вашего бота

## Шаг 3. Настроить конфигурацию

Откройте файл `config.py` и впишите:
```python
BOT_TOKEN = "ваш_токен_от_BotFather"
ADMIN_CHAT_ID = -1001234567890  # или ваш личный ID
```

## Шаг 4. Установить зависимости и запустить локально (для теста)

```bash
pip install -r requirements.txt
python bot.py
```

Если всё настроено верно — напишите боту `/start` в Telegram, должно появиться меню.

## Шаг 5. Бесплатный хостинг (чтобы бот работал 24/7)

### Вариант 1: Oracle Cloud Free Tier (рекомендую — бесплатно навсегда)
1. Зарегистрируйтесь на oracle.com/cloud/free
2. Создайте бесплатный инстанс (Always Free VM, Ubuntu)
3. Подключитесь по SSH, установите Python:
   ```bash
   sudo apt update && sudo apt install python3-pip -y
   pip3 install -r requirements.txt
   ```
4. Загрузите файлы бота на сервер (через `scp` или git)
5. Запустите бота в фоне, чтобы он не останавливался при закрытии терминала:
   ```bash
   nohup python3 bot.py &
   ```
   Либо лучше — настройте systemd-сервис для автозапуска при перезагрузке сервера (могу подсказать отдельно, если понадобится).

### Вариант 2: Railway.app (проще в настройке, но с ограничением по часам)
1. Зарегистрируйтесь на railway.app через GitHub
2. Загрузите код бота в репозиторий на GitHub
3. В Railway: New Project → Deploy from GitHub repo
4. В Variables добавьте `BOT_TOKEN` и `ADMIN_CHAT_ID` (и поправьте config.py, чтобы читал их из переменных окружения — см. ниже)
5. Railway сам запустит `python bot.py`

Если решите использовать Railway — скажите, я адаптирую `config.py` под переменные окружения (это правильнее для продакшена, чтобы токен не хранился в коде).

## Команды для администратора (в админ-чате)

- `/reply 5 Ваш заказ отправлен сегодня` — ответить клиенту по обращению №5
- `/open_tickets` — посмотреть список всех открытых обращений

## Что можно добавить дальше (по мере роста)

1. **Webhook вместо polling** — быстрее реагирует, меньше нагрузка на бесплатном хостинге
2. **Уведомления о статусе заказа** — если у вас есть интеграция с CMS сайта, бот сможет сам присылать «заказ отправлен», «заказ в пути»
3. **Кнопка "Оценить ответ"** после закрытия тикета — сбор обратной связи по качеству поддержки
4. **Английская версия FAQ**, если планируете иностранных клиентов
5. **Логирование ошибок** в отдельный файл или канал, чтобы сразу видеть сбои

Напишите, если что-то не заработает при запуске — разберём вместе.
